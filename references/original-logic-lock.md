# Original logic lock

These rules must remain unchanged from the original illustration workflow.

## Locked areas

### 1. Illustration quantity logic
Preserve the original image-count decision process.
Do not create extra images just because the style system is more flexible.

### 2. Cognition-anchor extraction
Continue selecting only the most visually meaningful anchors.
Do not illustrate every paragraph.

### 3. Scene planning
Continue using the original planning modes:
- flow-breakdown mode
- core-action mode

Continue converting abstract points into scenes through:
- character action
- object selection
- visible physical relationship
- result-oriented visual storytelling

### 4. Image structure
Preserve the original structure:
- one image, one main point
- independent images, not collage panels
- editorial insert image format
- 16:9 default
- large whitespace
- default colorless / pure white background
- very limited text
- not a poster wall
- not a complex infographic board

### 5. Delivery method
Preserve the original delivery method:
- generate one by one
- inspect one by one
- save one by one
- report filename/path, represented point, and insertion position

## Mandatory visual rules to preserve
- each image explains one key idea
- explain by picture first, not by text block
- use action, object, and physical relationship
- avoid large titles, long explanations, and heavy text zones
- each cognition anchor becomes its own image
- reader should understand the main point quickly

## Change-control rule
If a future request tries to expand the skill beyond style customization, do not silently modify the locked areas.
Flag the request as an additional extension beyond Caomei IP image’s intended scope.
