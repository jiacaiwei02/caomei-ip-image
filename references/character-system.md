# Character system

## Purpose
Maintain a consistent personal IP across all generated article illustrations.

## Character package
A usable character package should contain:
- character identity summary
- clean single-character reference image
- optional multi-view support images
- optional expression / pose support sheet
- character spec notes

## Role of expression and pose references
Expression and pose references are **auxiliary consistency references only**.

They are used to support:
- emotional consistency
- body proportion stability
- identity retention

They must not be treated as a whitelist of allowed poses.
Article scene actions must still come from article content.

## Character priorities
When generating article illustrations, preserve in order:
1. character identity
2. style consistency
3. scene-specific performance

## What not to copy into final illustrations
Do not copy character-sheet artifacts into editorial images, such as:
- direction labels
- view labels
- layout boxes
- swatch charts
- pose-sheet grids
- reference board text
