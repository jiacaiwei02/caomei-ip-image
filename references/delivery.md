# Delivery rules

## Delivery objective
Deliver illustrations in the same way as the original skill.

## For every generated image, report
- file name / path
- selected cognition anchor
- short description of the scene
- recommended insertion location in the article

## Insertion behavior
If the article format supports insertion and insertion is explicitly requested:
- follow the original insertion flow
- preserve a backup if editing the source document

If insertion is not supported or not requested:
- provide clear insertion instructions only

## Do not alter delivery style just because the style system was upgraded
The style system affects visual generation only.
